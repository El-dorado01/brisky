# Agent entry point

Before working on Brisky, read [the hackathon brief](docs/hackathon-agent-brief.md).
It contains the product direction, owner-supplied rules and judging rubric, contribution
boundaries, engineering priorities, and current execution constraints.

For every relevant change, distinguish **pre-existing functionality**, **work developed
during the hackathon**, and **planned or unverified behavior**. Update
`docs/hackathon-contributions.md` when implementing a new event contribution or changing
its status. Do not present the existing Brisky engine as newly built for the event.

The working tree contains ongoing work: preserve unrelated edits and inspect the actual
code before assuming a documented feature is implemented. Read any directory-specific
`AGENTS.md` before changing files there.
