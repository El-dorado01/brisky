# Bundled UI fonts

These are third-party copies of the font families already used by Brisky, not
newly designed hackathon assets. Local loading avoids build-time Google Fonts
downloads and leaves the existing CSS variables and typography intact.

TTF sources: https://github.com/google/fonts/tree/main/ofl
(`bricolagegrotesque`, `instrumentsans`, `ibmplexmono`, `dmsans`). The Latin
Love Ya Like A Sister WOFF2 is the existing Next.js Google Fonts cache copy.
The upstream family is https://github.com/google/fonts/tree/main/ofl/loveyalikeasister.
Each family's original SIL Open Font License and copyright notices are included
in its corresponding `*-OFL.txt` file.
